# 09 沙丁鱼理发铺

一句话：把一条过分讲究的条纹沙丁鱼梳成自己的样子，再给整条候场队伍拍照。

## 构图与材料

巨大鱼身横卧在珊瑚色理发椅上，钴蓝宽条纹穿过奶油色鱼腹，尾鳍像展开的小纸扇。头鳍有十五根可改变的骨条，嘴角有八缕可剪短的胡须；卷筒有纸芯、红线和圆形轮廓。背景使用偏移拱门、理发转柱、薄纸纹和刮白细线。不是换色界面，变化直接进入角色的几何形状。

## 已验证的真实作品研究

Winslow Homer，《Leaping Trout》，1889，水彩及石墨，Cleveland Museum of Art，藏品编号 1973.142。

来源：https://www.clevelandart.org/art/1973.142

在馆方页面验证题名、作者、年代与材料，并实际打开该页面提供的图片像素。画面中的鱼从近黑灰绿色背景中横向跃起；背部低明度、腹部呈连续亮白，靠近腹线可见很小的红橙斑；下方水面有几段不相连的水平白痕，大片水色并不平整。吸收的是“暗轮廓围住浅色鱼腹”“少量暖色点”“刮白造成纸上闪光”的观察，转译为夸张条纹、纸屑、划线和珊瑚色鳍。未临摹原作姿态或复制图像。

馆方条目明确允许复制、修改与分发该作品，并链接其 Open Access Initiative。成品仍完全使用程序自绘，没有加载、打包或嵌入馆方图片；研究图片不是生产资产。

## 1–3 分钟玩法

1. “梳头鳍”：在鱼头顶拖动。朝上梳会拉高骨条，左右梳会留下偏斜；相邻几根也会受到影响。
2. “剪胡须”：在嘴角的胡须上点按或慢拖。每次真正减少附近胡须的长度；纸屑落下。胡须有最短长度，不能无限剪。
3. “夹发卷”：点一撮头鳍夹上纸卷，再点同一撮取下。不同位置可以组合。
4. “换下一位”：把当前十五根头鳍的高度/倾斜/卷曲标记，以及八缕胡须长度，完整深拷贝进候场照片；新客人带着自己的初始头鳍出现。
5. “队列合照”：查看最多四位已服务客人与当前客人的实际造型。点画面回到椅子上。可反复换客、剪、梳、卷，不会自动抹掉既有照片里的编辑。

## API 与 QA

标准 IIFE 设置 window.ART，包含 title、subtitle、palette、tools、init、draw、pointer、action、stats。没有额外 HTML、外部依赖、网络读取或自建音频引擎。音效仅在实际操作时调用 window.SOUND.fx，并有 110ms 节流。

action ids：comb、scissors、rollers、next、photo。

下述归一化坐标以 1000×700 绘制尺寸为准：

- comb：down(.44,.23)，move(.49,.14)，up。combMoves 至少为 2，fin 中的高度/倾斜发生变化。
- scissors：点(.744,.56)，间隔至少 100ms 再点(.73,.55)。snips 至少为 2，beardLengths 缩短。
- rollers：点(.45,.23)。fin 至少有一个 curl=true。
- next：customersServed=1；portraits[0].fin 与 beardLengths 必须与换客前的对应数组完全相等。
- photo：photoMode=true。再次执行或点画面后回到 false。

draw 使用等比居中的 1000×700 设计空间，手机不拉长鱼身。空余部分延续纸纹。pointer 将宿主的归一化坐标根据最近的视口反算；任意尺寸的精确点击可用 s=min(w/1000,h/700)，ox=(w-1000s)/2，oy=(h-700s)/2，再把设计坐标映射为 ((ox+X·s)/w,(oy+Y·s)/h)。

已完成 Node 语法检查、数值绘图 mock、完整状态链、resize(dt=0)保留状态与 init 重置测试。100 位客人压力测试后合照仍最多 4 张，动态粒子最多 65；头鳍 15 根、胡须 8 缕、背景纹理 780 条，均有固定上限。实际使用 @napi-rs/canvas 离屏渲染并查看编辑后的合照像素，随后修正合照上方说明和鱼鳍的间距。未执行浏览器 QA。

主要 stats：tool、customersServed、snips、combMoves、rollerChanges、photoMode、currentId、currentEdits、fin、beardLengths、portraits、particleCount。

## 与既有作品的区别

这是一套有职业场景和顾客记忆的角色造型工具。声音只是剪、梳、夹卷的反馈；核心结果是几何编辑和跨客人保留的真实合照，不是既有节拍演奏、拟声角色、面具换脸、表情纸带或调色面板的替换皮肤。
