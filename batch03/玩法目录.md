# 光的研究 · 十件可玩艺术作品

十件作品均为本次独立编写的单文件网页，可下载HTML或解压ZIP离线打开。声音默认关闭，点击Sound off后由手势解锁；Reset可以重新开始。参考方向不构成独占版权声明。

手机竖屏390×844与桌面1440×900已完成实际浏览器输入测试；未做实体手机测试或人工听音。

## 01 · 玻璃果园 / Glass Orchard

[私有试玩](https://wentaopeng714-cmd.github.io/little-worlds-artworks/batch03/01-glass-orchard/) · [独立HTML](01-glass-orchard.html) · [独立ZIP](01-glass-orchard.zip)

Grow 模式在空处点按种下新树，最多六棵；靠近树根点按或长按加速分叉，拖动改变玻璃色相。Prune 模式沿枝叶拖动剪除其后代。组合 Bloom、Wind 与 Day/Night 形成玻璃冬枝、发光果园、风中彩色树林。Reset 重建初始树。

原作参考：[原作](https://fff.cmiscm.com/#!/section/planttrees)。

改编差异：保留可持续种树、分叉生长与昼夜主题；新绘制透明棱镜树干、晶体花叶、土壤光圈，新增多树色相塑形、剪枝、风与花期。不使用原作图形资产。

## 04 · 镜港

[私有试玩](https://wentaopeng714-cmd.github.io/little-worlds-artworks/batch03/04-mirror-harbor/) · [独立HTML](04-mirror-harbor.html) · [独立ZIP](04-mirror-harbor.zip)

在上半部轻点或拖动，生成带灯窗的层叠浮岛。停留半秒以上会持续抬高最后生成的建筑。

在水面拖动，会留下椭圆波圈并扰动逐层倒影；速度影响扰动强度。

Build/Erase 切换建造和擦除；Wind 切换三档波动速度，Water 切换三个水位。

Blue hour / Rose dusk / Jade night 切换三组完整夜景气氛。组合建筑布局、水位、波动和色彩可持续游玩。

Reset 重建初始七座浮岛；Sound off / on 控制原创合成泛音。

原作参考：[原作](https://fff.cmiscm.com/#!/section/ripples)。

改编差异：借鉴原作建筑与扰动倒影的空间关系。改为原创层叠浮岛建筑、彩色灯窗、弧形空中层次与切片水面；允许直接建造、抬高、擦除和混合调节水位、风与气氛。未复刻原作纽约天际线。

## 05 · 字螺

[私有试玩](https://wentaopeng714-cmd.github.io/little-worlds-artworks/batch03/05-word-conch/) · [独立HTML](05-word-conch.html) · [独立ZIP](05-word-conch.zip)

围绕字螺中心拖动，文字会按手势角度直接旋转，松手后保留惯性。

在原处停留半秒，会缓慢展开字螺；松手后慢慢收拢。

较快划动后松手，诗句中的字会散落成独立漂浮文字。

Shell / Ribbon / Orbit 切换三种不同排字拓扑；Split 在一只大螺与三只互相错落的字螺之间切换。

Pearl / Deep ink / Vermilion 改变整体纸色、字色、强调色；Words 可输入最多160字个人短句并重新编织。

Reset 清除散字、惯性与旋转，保留当前个人短句与所选版式。Sound off / on 控制原创合成音。

原作参考：[原作](https://fff.cmiscm.com/#!/section/spiral)。

改编差异：借鉴原作密排文字螺旋与旋转操作。自行按字符几何排版，加入三种文字结构、三螺错落组合、朱砂与珍珠纸的编辑气质、留句编织、长按展开与释放惯性散字。所有默认诗句与排版算法为本次原创。

## 06 · 灯光漂流

[私有试玩](https://wentaopeng714-cmd.github.io/little-worlds-artworks/batch03/06-lantern-drift/) · [独立HTML](06-lantern-drift.html) · [独立ZIP](06-lantern-drift.zip)

拖动会推动靠近手势的前景光斑，并产生按景深分层的视差。

原处停留半秒可聚拢周围光滴；松手会释放一圈新光滴。

快速划动松手会投掷周围光滴；快速双点会直接产生扩散爆发。

Soft / Glass / Dream focus 改变光圈边缘与整体虚焦；Round / Six blades / Anamorphic 改变镜头光圈形态。

Copper tide / Velvet dusk / Ember grove 切换完整光色气氛。Freeze 可以静止当前漂流并继续使用拖动或聚拢；Resume 恢复漂流。

Reset 重置82个原始光滴与视差。Sound off / on 控制原创轻柔合成音。

原作参考：[原作](https://fff.cmiscm.com/#!/section/bokeh)。

改编差异：借鉴原作大幅散焦圆形光斑、加色层叠和指针视差。自行绘制铜金与青绿镜头光滴，增加可近处施力、聚拢、投掷、爆发、对焦、光圈与冻结，使景深中的光线可持续组织成画。

缓慢拖动，将一笔变成数十根弯曲的发光纤维。快速划动也立即留下完整丝束；停留会在笔尖叠出细小卷曲。Nacre / Ember / Lagoon 切换之后的笔触颜色，叠加可混色。2 / 4 / 6 folds 改变下一笔的旋转对称数，Reflect 打开镜像，Spiral 将下一笔逐步拧成旋涡。Erase 以同样的对称规则擦除绸面，Undo 撤销最近一段，Age 让已画绸缎慢慢暗淡。Reset 清空；700ms 内再点一次 Reset 恢复构图。Sound on 解锁合成低鸣与少量音阶。

原作参考：[原作](https://weavesilk.com/)。

Steer 下在画布拖动弯曲体积洋流，轻点插入旋涡闸点（最多6个，后续替换最早的点）。Orbit 下横拖旋转三维视角，纵拖升降观察角度。Freeze 把动态洋流定格成雕塑后仍可 Orbit 观察。Dust 令紧束丝带散开成颗粒云，Turbulence 叠加急湍。三种色组、Clear gates、Reset 与 Sound 开关可自由组合。
