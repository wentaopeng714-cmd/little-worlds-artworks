# 糖光折炼

拉出闪亮的糖带，绕一只结，敲成碎片，再用热光把它炼回新的形状。

拉糖：按住现有糖带局部拖动，保留整个盘卷雕塑。热熔会把碎糖重组成5–7条不同宽度与颜色的糖带，可连续炼出不同作品。

玩法：依次尝试“拉糖 / 结糖 / 敲碎 / 热熔 / 换味”，在画面主体上点按或拖动。可反复组合，不设分数与限时。重做保留声音设置。离开页面会停止声音。

技术：独立程序绘制 Canvas 2D；原创 Web Audio 合成音乐与操作音效，无外部图像、音频、字体请求。解压后直接打开 index.html。
