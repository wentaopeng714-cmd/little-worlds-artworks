# Light Studies · Batch 03

十件独立实现的可玩艺术网页；每件子目录 index.html 与同名 HTML 是完全内联的离线页面。对应 ZIP 可直接下载、解压并打开 index.html。

六件参考 FFF 的不同交互方向，其余参考 Silk、Neonflames、Fluid Paint 与 Particle Flow。未复用原作代码、图像、音乐或商标；来源、许可核实与具体差异见中文玩法目录和参考许可。

移动390×844和桌面1440×900每件连续60–90秒真实手势测试及离线压力检查通过；未做实体手机及人工听音测试。

本批代码与程序美术独立编写；未附加MIT等再分发许可证，不主张对参考方向或AI生成内容拥有独占版权。
