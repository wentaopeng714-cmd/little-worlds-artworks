# 皂石切片

切开一块温柔的矿层，镶入彩色碎皂，再让泡沫把它慢慢显露。

玩法：依次尝试“切层 / 镶料 / 压花 / 起泡 / 擦洗”，在画面主体上点按或拖动。可反复组合，不设分数与限时。重做保留声音设置。离开页面会停止声音。

技术：独立程序绘制 Canvas 2D；原创 Web Audio 合成音乐与操作音效，无外部图像、音频、字体请求。解压后直接打开 index.html。

参考：https://haruharustudio.com/products/ondo-body-soap-apple-sage

乳白块体与彩色碎屑的材质、错位陈列与柔和影子；仅灵感观察，未使用产品照片、商标或包装。
