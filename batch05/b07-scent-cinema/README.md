# 香气试映室

把花、柑橘与木调喷进光里。转动瓶身，留下属于此刻的试香签。

玩法：依次尝试“花调 / 柑调 / 木调 / 转瓶 / 采样 / 清风”，在画面主体上点按或拖动。可反复组合，不设分数与限时。重做保留声音设置。离开页面会停止声音。

技术：独立程序绘制 Canvas 2D；原创 Web Audio 合成音乐与操作音效，无外部图像、音频、字体请求。解压后直接打开 index.html。
