# Little Worlds — 九件轻交互网页艺术

当前作品保留原编号：01、02、03、04、05、07、08、09、10。06已从本合集撤下。

打开 index.html 可浏览全部作品；每件子目录的 index.html 均为独立、全内联的可玩网页，相同编号 ZIP 可下载后离线运行。

- 01 捏脸星人：多部位互动与组合变身。
- 02 弹性花园：变种、授粉与杂交育种。
- 03 流彩池：混色、涡流与梳理分层。
- 04 折纸剧场：四种形态、翻面与折痕。
- 05 重力音符：可编辑反弹结构与音符分裂。
- 07 声波水庭：波源干涉与石阵共鸣。
- 08 挤雨云：天气、开花与传种循环。
- 09 昼夜小屋：日夜、窗灯和环境联动。
- 10 织光线：三种针法、移动钉点与断线重织。

原生Canvas和WebAudio，无第三方运行库、CDN或付费AI接口。支持触屏与鼠标，首次用户手势解锁声音。每件均有静音与重置。

源文件为用户制作，未附加MIT等公开许可证。公开访问不表示授权任意再分发；AI生成内容的可版权性和独占性不作法律保证。
