# 绳结染布

先打结留下空白，再分区染入颜色。展开布面，读一张由你折叠过的彩色地图。

玩法：依次尝试“打结 / 胭脂 / 靛蓝 / 金黄 / 展开 / 再折”，在画面主体上点按或拖动。可反复组合，不设分数与限时。重做保留声音设置。离开页面会停止声音。

技术：独立程序绘制 Canvas 2D；原创 Web Audio 合成音乐与操作音效，无外部图像、音频、字体请求。解压后直接打开 index.html。
