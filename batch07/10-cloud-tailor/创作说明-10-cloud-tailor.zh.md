# 10 云被裁缝

一句话：给青紫夜色里的瞌睡大头盖一床云被，把逃跑的星星重新缝进梦里。

## 构图与材料

大头角色偏在画面左上，重重的眼皮、淡粉斜划腮红和弯曲夜帽组成一块安静的纸毡剪影。右上悬着线轴与长针；下方是一张由青蓝、灰紫布块构成的云被。云被拥有 66 个可变形网格节点、波浪状边缘、细密纬线和虚线绗缝。补丁、孔洞和针脚记录在被面坐标里，拉扯与折叠后会真正随布移动。

## 已验证的真实作品研究

Odilon Redon，《Les Yeux clos》（《闭眼》），1890，布面油画裱于纸板，Musée d’Orsay，RF 2791。

来源：https://www.musee-orsay.fr/en/artworks/les-yeux-clos-476

在奥赛官方页面核对作者、年代、材料与馆藏编号，并实际查看馆方提供的图像像素。人物被褐色头发包围，头微微倾斜，眼皮低垂；背景是带细粒的灰蓝，脸部亮暗差很柔和。胸像向画面下方消融，底部有一条朦胧的水平亮带。吸收的是“安静的大头与水平的软层相遇”的构图和轻薄颗粒感，重新设计成纸毡角色、云被和青紫配色，不复制人物形象、原画轮廓或背景。

页面提供的研究图片注明 RMN-Grand Palais / Musée d’Orsay 及摄影者版权。这里只做研究观看，不声称该图片可以自由再分发，也没有接受图片下载协议。成品所有角色、布纹、月亮和星星均由 Canvas 自绘，不含馆方照片或其他第三方视觉资产。

## 1–3 分钟玩法

1. “拉云被”：捏住被面拖动，会影响附近节点，留下可继续编辑的起伏。补丁、洞和针脚跟着位置变化。
2. “缝月补丁”：点击云被缝上一弯金色月亮；再点已存在的月亮可转动朝向。月亮的环绕小针脚是可见的。
3. “开洞漏星”：点击开洞，亮星从洞里持续向上飘；同一洞再点会放大孔径。漏洞增加时暖意降低，角色的一只眼会稍稍醒来。
4. “缝好小洞”：在洞上点四次，或以足够慢的速度拖针。洞逐步收窄，交叉缝线逐渐出现，第四针后停止漏星。修补的痕迹保留。空白处也可缝自由针脚。
5. “折一折”：依次尝试折下右角、掖起下摆、重新摊开。原来的月亮、孔洞和修补痕迹保留，之后仍可拖动、开洞和修补。

## API 与 QA

标准 IIFE 设置 window.ART，包含 title、subtitle、palette、tools、init、draw、pointer、action、stats。无 HTML、外部依赖或网络读取。音效只经 window.SOUND.fx 触发，节流为 150ms；针线操作另有 85ms 节流。

action ids：pull、moon、hole、sew、fold。

下述归一化坐标以 1000×700 绘制尺寸为准：

- moon：点(.52,.69)，断言 moonPatches=1。
- hole：点(.70,.73)，断言 openHoles=1；推进动画约 1 秒，starsEmitted 应大于 5。
- sew：读取 holes[0] 的 x、y，在 (x/1000,y/700) 连点四次，各次相隔至少 100ms，断言 openHoles=0、repairs=1。
- pull：读取 patches[0] 的 x、y，down 后拖到设计坐标 (+40,-30)px，再 up；断言 pullMoves>0、deformation>0，而且补丁坐标改变。
- fold：folds=1，同时 moonPatches=1、repairs=1，记录没有丢失。

渲染使用等比居中的 1000×700 设计空间，窄屏余白延续夜色星点。pointer 会反算最近视口；任意尺寸的精确点击映射为 ((ox+X·s)/w,(oy+Y·s)/h)，其中 s=min(w/1000,h/700)，ox=(w-1000s)/2，oy=(h-700s)/2。

已完成 Node 语法检查、数值绘图 mock、编辑状态链、resize(dt=0)保留状态与 init 清净重置。压力测试验证月补丁最多 18、洞记录最多 14、活动星星最多 80、自由针脚最多 45，网格固定 66 节点；连续折叠 80 次无异常。使用 @napi-rs/canvas 离屏渲染并实际查看补月、开洞、修补、拉扯、折叠后的像素，修正了夜帽星形与英文副标题的重叠。未执行浏览器 QA。

主要 stats：tool、moonPatches、totalMoonsPlaced、openHoles、holesMade、repairs、looseStitches、folds、foldMode、pullMoves、starsEmitted、liveStars、patches、holes、deformation、nodeCount。

## 与既有作品的区别

这是持续编辑一块有附着物的软织物，并在“漏星、缝补、变暖”的小叙事中反复组合的作品。变化来自网格形变、孔洞状态和材料坐标，不是声音节拍器、已有动物动作、纸带表情、蜡章印记或换色效果的翻版。
