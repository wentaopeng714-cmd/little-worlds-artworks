# 唱片封面工房

在套封上贴印、拖动构图、旋转版式与展开折页。角落的小黑胶提供原创声轨。

选择贴印后点按封套，再拖动当前印墨形状排列；版式工具能拖动旋转整体图形；折页展开侧页，换声切换原创合成乐句，唱针给角落的附属声源落针。最多18层叠印，可无限重排、翻折和重新设计。主要交互是封套排版，没有手划转盘。

技术：独立 Canvas 2D 和原创 Web Audio，所有依赖本地打包；解压后打开 index.html，无网络素材。
